## Personal Product Development

### MTP (Mapping the Prompt)

**June 2025-Present**

MTP is a personal project for treating generative AI output styles and response tendencies not only as natural-language instructions, but also as coordinates, intensity values, and presets.

The goal is to make output adjustments reusable through short specifications and to compare multiple response tendencies without writing long natural-language instructions each time.

The project mainly consists of:

- Framework design for mapping
- Agent skill development
- CLI / ZIP distribution
- Bilingual documentation site built with Astro / Starlight
- Site deployment and release workflows through GitHub Actions
- Distribution management through GitHub Releases and release JSON
- Input compiler and file operations in Python
- `llms.txt`, Raw Markdown, and Copy Markdown access paths
- Comparison records for agent skills across multiple AI models
- Design history and implementation logs published on Zenn and Medium

In this project, I provide documentation for human readers as well as machine-readable access paths that AI assistants can reference more easily. Related work also includes technical documents in paper-like formats using LaTeX, BibTeX, and TikZ.
